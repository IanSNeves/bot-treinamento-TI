Checklist Geral do Projeto: bot-treinamento-TI

[ ] Fase 1: Planejamento e Estruturação

[ ] Definir o escopo inicial.
[ ] Configurar o ambiente de desenvolvimento.
[ ] Criar e configurar o repositório no GitHub.
[ ] Definir o fluxo de trabalho com Git e as convenções de nomenclatura.
[ ] Fase 2: Desenvolvimento do Core do Bot (Sem IA)

[ ] Criar a estrutura básica do projeto (pastas e arquivos).

[ ] Implementar o primeiro fluxo de treinamento estático (passo a passo para impressoras).
[ ] Fase 3: Integração com Inteligência Artificial

[ ] Obter uma chave de API de um serviço de IA (como Google Gemini ou OpenAI).

[ ] Usar a IA para guiar o usuário, garantindo que ele não fuja do tópico.
[ ] Fase 4: Expansão e Melhorias

[ ] Adicionar novos fluxos de treinamento (formatação, atualização de software).
[ ] Refatorar o código para torná-lo mais limpo e modular.
[ ] Coletar feedback e melhorar as respostas do bot.
